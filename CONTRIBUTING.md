# Contributing Guidelines

Thank you for helping improve the **Cybersecurity Roadmap**! Community contributions keep this resource fresh, relevant, and accurate for new learners and seasoned practitioners alike.

---

## 💡 Ways to Contribute

1. **Fix Broken Links**: Platforms periodically restructure course URLs. If you find a dead link, submit a PR with the updated link.
2. **Add New High-Quality Labs**: Recommend free or accessible labs (TryHackMe rooms, HackTheBox modules, CyberDefenders challenges, PortSwigger topics).
3. **Expand Cheatsheets & Guides**: Contribute practical commands, detection rules (Sigma), or lab guides.
4. **Improve Clarity**: Fix typos, reformat tables, or enhance Mermaid diagrams.

---

## 🛠️ Contribution Workflow

1. **Fork the Repository**:
   Click the "Fork" button at the top right of GitHub.
2. **Clone Your Fork**:
   ```bash
   git clone https://github.com/<your-username>/cybersecurity_roadmap.git
   cd cybersecurity_roadmap
   ```
3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/add-new-resource
   ```
4. **Commit Your Changes**:
   Make clear, concise commit messages:
   ```bash
   git commit -m "docs: add Wazuh SIEM detection exercises to blue-team guide"
   ```
5. **Push and Open a Pull Request**:
   Push to your fork and submit a PR against `main`.

---

## 📝 Guidelines

- Focus on legal, ethical, and defensive/educational content only.
- Prefer free or high-value accessible training resources over proprietary/expensive products.
- Maintain clean Markdown syntax and valid GitHub links.
